# Data and result files

## Input fields

Inputs are stored in `data/<synthetic|real>/<ID>/`. Node order is city-major, followed by age group.

| File | Contents |
|---|---|
| `states_age.npy` | Time x node x state: S, I, R, gammaI for synthetic data; S, E, I, R, gammaI for real data |
| `states_age_noisy.npy` | Multiscale simulation observations with noise |
| `states_city.npy`, `states_city_noisy.npy` | City-total synthetic states: S, I, R, gammaI; the latter includes noise |
| `time.npy` | Simulation time steps |
| `contact_matrix.npy` | Node contact matrix |
| `contact_mat.npy` | Spain node contact matrix |
| `dist_mat.npy` | City distance matrix |
| `group_population.npy` | Ontario age-group population |
| `city_population_order.csv` | City order and population |
| `age_order.csv` | Spain age-group order |
| `node_labels.json` | City and age-group display names |
| `source_schema.json` | Source table field names and city aliases |
| `aligned_dates.csv` | Dates corresponding to the state observations |
| `states_age_raw_flat.csv` | Ontario observations in a flat table |
| `Baidu_Migration*series.npy` | Directed city OD trajectories with a zero diagonal |
| `G_L_series.npy`, `true_GL_by_city.npy` | Simulation infection operators |
| `G_E*series.npy` | Simulation transport operators |
| `generate_SIR_data.py` | Scenario simulation and dataset generation |

For Spain, `Baidu_Migration_series.npy` contains Spanish OD flows.

## Output fields

The tables below describe stored reference results and files generated by prediction or training.

| File | Contents |
|---|---|
| `best_model.pth` | Model parameters, selected epoch and monitoring loss |
| `pretrained_MLP_mob.pth` | Mobility model parameters, where used |
| `pred_u.npy` | gammaI, time x node x 1 |
| `pred_u_city.npy` | City-total gammaI, time x city x 1 |
| `GE_city.npy` | City transport operator, time x city x city |
| `GL_age.npy` | Node contact operator, time x node x node |
| `pred_mobility.npy` | Predicted OD, time x city x city |
| `pred_*mobility.xlsx` | Reference OD tables |
| `case_forecast.png` | Node gammaI observations, fit and forecast |
| `city_forecast.png` | City-total gammaI observations, fit and forecast |
| `mobility_forecast.png` | Directed city OD observations and forecast |
| `loss_history.csv` | Training and monitoring losses by epoch |
| `training.log` | Experiment console output |

Each stored scenario includes `best_model.pth`, `config.yaml`, `pred_u.npy`, and `pred_u_city.npy`.
Stored operator and OD files vary by scenario. New predictions include both operator arrays; multicity scenarios also include `pred_mobility.npy`.
`results/<synthetic|real>/<ID>/config.yaml` contains checkpoint prediction settings.
